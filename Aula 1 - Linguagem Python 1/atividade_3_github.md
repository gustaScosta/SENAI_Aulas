# Atividade 3 - Criar conta no GitHub e portfolio

## Objetivo

Criar uma conta no GitHub e preparar um repositorio para servir como portfolio de estudos.

## Tarefas

1. Acessar o GitHub:

   https://github.com/

2. Criar uma conta ou entrar em uma conta existente.

3. Criar um novo repositorio.

4. Instalar o Git:

   https://git-scm.com/

5. Verificar se o Git esta instalado:

   ```bash
   git --version
   ```

6. Abrir a pasta do projeto no terminal.

7. Iniciar o repositorio:

   ```bash
   git init
   ```

8. Verificar o status:

   ```bash
   git status
   ```

9. Adicionar os arquivos:

   ```bash
   git add .
   ```

10. Criar um commit:

    ```bash
    git commit -m "primeiro commit"
    ```

11. Conectar ao repositorio remoto:

    ```bash
    git remote add origin LINK_DO_REPOSITORIO
    ```

12. Enviar os arquivos para o GitHub:

    ```bash
    git push --set-upstream origin master
    ```

## Entrega

Enviar o link do repositorio criado no GitHub.
