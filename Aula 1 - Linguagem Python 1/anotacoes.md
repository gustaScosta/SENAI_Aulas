## Introducao a computacao

A computacao estuda e desenvolve sistemas computacionais, envolvendo hardware e software. Ela busca automatizar processos por meio de algoritmos e programas.

Um computador e uma maquina eletronica que processa informacoes de acordo com um conjunto de instrucoes programadas.

Ideia principal:

```text
PROBLEMA -> ALGORITMO -> SOLUCAO
```

## Historia da computacao

A historia da computacao passou por varias fases, desde dispositivos mecanicos para calculos ate tecnologias modernas, como computacao em nuvem, inteligencia artificial e computacao quantica.

Algumas pessoas importantes:

- Ada Lovelace: considerada a primeira programadora.
- Alan Turing: considerado uma das bases da ciencia da computacao.
- Grace Hopper: pioneira em linguagens de programacao e no COBOL.
- Tim Berners-Lee: criador da World Wide Web.
- Bill Gates: importante nome da popularizacao dos computadores pessoais.

## Importancia da programacao

Programar e escrever instrucoes para que o computador execute tarefas. A programacao ajuda a desenvolver:

- pensamento logico;
- resolucao de problemas;
- criatividade;
- automacao de tarefas;
- criacao de sistemas, sites, aplicativos e ferramentas.

## Linguagens naturais e linguagens de programacao

A linguagem natural e a linguagem humana, como portugues, ingles ou espanhol.

A linguagem de maquina e composta por 0 e 1.

As linguagens de programacao ficam entre a linguagem humana e a linguagem de maquina, permitindo que pessoas escrevam comandos que depois serao entendidos pelo computador.

## Compiladores

Um compilador traduz o codigo-fonte inteiro de uma linguagem de alto nivel para codigo de maquina ou outro formato executavel.

Exemplos de linguagens muito associadas a compilacao:

- C
- C++
- Pascal
- Fortran

Caracteristicas:

- traduz o programa antes da execucao;
- pode gerar um arquivo executavel;
- costuma detectar varios erros antes de rodar o programa;
- pode ter melhor desempenho em muitos casos.

## Interpretadores

Um interpretador le e executa o codigo linha por linha ou bloco por bloco, sem precisar gerar antes um executavel completo.

Exemplos de linguagens interpretadas ou muito associadas a interpretacao:

- Python
- JavaScript
- Ruby
- Perl

Caracteristicas:

- executa o codigo diretamente;
- facilita testes rapidos;
- geralmente e mais simples para iniciantes;
- pode depender do interpretador instalado na maquina.

Principais objetivos da linguagem:

- automacao;

## Git e GitHub

Git e uma ferramenta de versionamento de codigo.

GitHub e uma plataforma para hospedar repositorios Git online.

Comandos basicos:

```bash
git --version
git init
git status
git add .
git commit -m "mensagem do commit"
git remote add origin LINK_DO_REPOSITORIO
git push --set-upstream origin master
```

Etapas principais:

1. Instalar o Git.
2. Criar uma conta no GitHub.
3. Criar um repositorio.
4. Iniciar o repositorio local com `git init`.
5. Adicionar arquivos com `git add .`.
6. Criar um commit com `git commit`.
7. Conectar o repositorio local ao GitHub.
8. Enviar os arquivos com `git push`.
