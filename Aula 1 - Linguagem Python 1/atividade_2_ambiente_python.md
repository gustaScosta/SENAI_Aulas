# Atividade 2 - Ambientacao e ambiente Python

## Objetivo

Preparar o computador para programar em Python.

## Tarefas

1. Instalar o Python pelo site oficial:

   https://www.python.org/

2. Durante a instalacao, marcar a opcao para adicionar o Python ao PATH.

3. Verificar a instalacao no terminal:

   ```bash
   python --version
   ```

   ou:

   ```bash
   py --version
   ```

4. Instalar ou abrir um editor de codigo, como Visual Studio Code.

5. Criar uma pasta para os estudos de Python.

6. Criar um arquivo chamado `aula.py`.

7. Escrever um primeiro teste:

   ```python
   print("Ola, Python!")
   ```

8. Executar o arquivo pelo terminal:

   ```bash
   python aula.py
   ```

## Resultado esperado

O terminal deve mostrar:

```text
Ola, Python!
```
